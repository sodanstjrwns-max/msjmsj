# 치과의사 문석준 — 독립 개인 홈페이지

## 현재 버전: 브라운 전면 재설계

- 코드명 `webapp`, 작업 위치 `/home/user/webapp`, 브랜치 `main`.
- 업데이트: 2026-09-24.
- 사용자가 이전 파란 편집형 시안을 거절하고 비디와 같은 갈색, 더 강한 시각적 인상의 전면 개편을 요청했다. 기존 구조에 색만 바꾸지 않고 첫 화면, 콘텐츠 편집, 타이포그래피, 사진 배치와 반응형을 재구현했다.
- 목표: 환자분이 치과의사 문석준의 진료 태도와 글·책·영상을 알아가는 독립 개인 사이트. 병원 하위 소개 페이지나 페이션트 퍼널 판매 페이지가 아니다.
- 기술: Hono JSX + TypeScript, 자체 CSS/JS, Vite, Cloudflare Pages 호환.
- 현재 상태: 샌드박스 검토용. **정식 배포와 도메인 연결은 하지 않았다.**
- 미리보기: https://3000-izzaj9m15pt6fbzab9xou-de59bda9.sandbox.novita.ai/?v=2
- 프로덕션 URL: 미정.
- robots.txt, robots 메타, X-Robots-Tag로 검색 제외 요청. 이는 인증/접근 제한이 아니므로 주소를 아는 사람은 접근 가능하다.

## 디자인 방향

비디 공식 CSS `https://bdbddc.com/css/site-v5.css`에서 확인한 실제 브랜드 토큰:
- 메인 `#6B4226`
- 밝은 갈색 `#8B6344`
- 진한 갈색 `#4A2E1A`

독립 사이트에는 이를 바탕으로 딥 브라운 `#281B14`, 밝은 종이색, 구릿빛 보조색을 조합했다.

- 화면 전체를 쓰는 브라운 포스터형 첫 화면. '충분히 / 듣습니다'를 분리한 큰 글자와 중앙의 실제 인물, 여백의 이름·소속을 한 구도로 설계.
- 원본 프로필의 밝은 단색 배경만 비생성형 픽셀 분리로 제거. 얼굴·나이·체형을 AI로 생성하거나 바꾸지 않았다. 원본과 분리본을 함께 보관한다.
- 배경의 얇은 궤도선, 작은 입자 질감, 짧은 등장 애니메이션. 스크롤을 강제로 이동하거나 잠그지 않으며 자동 재생 소리 없음.
- 일반 화면에서는 스크롤에 따라 궤도가 완만하게 회전하고 읽기 진행선이 변한다. 제목은 위치를 조금 이동하며 드러난다. 본문을 투명하게 숨기지 않는다.
- 같은 크기의 카드 목록 대신 비대칭 영상·칼럼, 넓은 저술 목록, 어두운 인물 소개, 원형 진료 안내로 리듬을 구성.
- 한국어는 sans-serif, 일부 영어 편집 표시는 시스템 serif를 사용한다. 영문 인명 철자를 임의로 만들지 않았다.
- 모바일 첫 화면의 글자·인물·이름은 별도 좌표와 크기로 재배치.
- 사각 도형 심벌은 이 시안을 위해 만든 장식 그래픽이며 공인 로고·학위·자격 마크가 아니다.

## 완료 기능과 경로

| 경로 | 내용 |
| --- | --- |
| `/`, `/#top` | 포스터형 첫 화면, 충분히 듣습니다, 실제 사진과 소속 |
| `/#approach` | 환자분 질문에 따른 경청·이해·선택 탭 |
| `/#records` | 실제 영상 1개, 칼럼 1편, 책 2권; 유형 필터 |
| `/#about` | 문석준 소개, 소속·학력·진료 관심, 접힌 운영 관련 저술 |
| `/#visit` | 서울비디치과 예약 및 위치·이용 안내 |
| `/robots.txt` | 검토 단계 검색 제외 |
| `/static/*` | 자체 서빙 이미지, 글꼴, 스타일, 스크립트 |

- 모바일 메뉴: 펼침, 링크 선택 후 닫기, 외부 클릭·Escape 닫기.
- 질문 탭: 위/아래 방향키, Home/End, 선택 상태와 ARIA 관계.
- 콘텐츠 필터: 전체/글/책/영상, 결과 개수 전달, 필터에 맞춘 재배치.
- 영상 재생 버튼을 누른 뒤에만 YouTube iframe 삽입. 원본 YouTube 링크 병행.
- 외부 링크에는 새 탭 안내 및 noopener noreferrer.
- 본문 건너뛰기, 포커스 표시, 이미지 설명, 움직임 감소 환경 지원.
- 자바스크립트가 없을 때도 전체 본문·자료·병원 링크 유지.
- 개인 예약/문의 폼, 회원가입, 결제, 추적 스크립트 없음.

### 새로 편집한 문안

'충분히 듣습니다'는 당사자의 직접 정정 표현이다. 나머지 소개·질문·콘텐츠 요약은 사용자의 초안에 근거해 새로 편집한 문안이다. 재설계에서 추가한 '듣는다는 건, 한 사람을 알아가는 일', '나의 말보다, 당신의 이야기부터', '대화의 다음 장' 등의 문구도 새 문안이며 인터뷰 발췌나 최종 승인 인용문이 아니다.

## 사용과 로컬 실행

메뉴 또는 첫 화면 아래 화살표로 읽는다. 질문 탭에서 마음에 가까운 주제를 선택하고, 글·영상 영역에서 유형별 자료를 찾아본다. 실제 진료는 병원 경로로 이동한다.

```sh
cd /home/user/webapp
npm run build
pm2 start ecosystem.config.cjs
curl http://localhost:3000
npm test
```

기존 서버가 실행 중이면 중복 시작하지 않는다. 재시작 시 PM2 프로세스를 멈추고 3000 포트를 확인한 후 빌드 및 PM2 재시작을 한다. 로그는 `pm2 logs webapp --nostream`.

글꼴은 Pretendard v1.3.9의 본문 문자 부분집합이다. Reserved Font Name을 사용하지 않도록 내부/CSS 이름을 MoonSans로 변경했고 OFL 라이선스는 `/static/font-license.txt`에 있다. 문안을 추가할 때 부분집합을 갱신한다.

## 다음 확인 사항과 공개 작업

1. 새 브라운 시각 방향, 새 문안, 대표 콘텐츠 및 운영 관련 저술 노출 범위를 본인이 검토한다.
2. 고해상도 실제 인물 사진, 공개 동의가 확보된 실제 경청 장면, 임상·권리 검토를 마친 대표 설명자료를 추가하면 좋다. 생성형 가상 진료 사진으로 대체하지 않는다.
3. 자격·세부 약력은 증빙 확인 전 추가하지 않는다. 책 표지·새 원고 공개 범위, 공식 영문 이름·협업 연락처·다국어 필요 여부도 미정이다.
4. 사용자 공개 승인과 배포 경로 선택 후 도메인 DNS/HTTPS, canonical·OG·사이트맵, 검색 제외 해제를 진행한다. 지금은 실행하지 않는다.
5. 실제 휴대폰에서 원본 영상, 서점, 병원 예약 동작을 최종 확인한다.
6. 서울비디치과 의료진 페이지에 '치과의사 문석준 개인 홈페이지' 링크를 병원 운영 측이 별도로 반영한다. 현재 병원 사이트는 수정하지 않았다.
