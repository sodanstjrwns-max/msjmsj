- 코드명: `webapp`; 작업 위치 `/home/user/webapp`; Git 브랜치 `main`.
- 기준일: 2026-09-23.
- 목표: 환자분이 치과의사 문석준의 진료 태도와 글·책·영상을 알아가는 개인 거점. 서울비디치과의 하위 페이지나 페이션트 퍼널 판매 페이지가 아니다.
- 기술: Hono JSX 서버 렌더링, TypeScript, 자체 CSS, 작은 클라이언트 JavaScript, Vite + Cloudflare Pages 호환 빌드.

- 프로덕션 URL: 미정.
- `robots.txt`, robots 메타, `X-Robots-Tag`에 검색 제외 요청. 이는 인증이나 접근 제한이 아니므로 미리보기 주소를 아는 사람은 접근 가능하다. 정식 공개 전에 별도로 승인받아 설정을 변경해야 한다.

## 인물 해석과 디자인

핵심은 설명 능력을 자랑하기 전에 환자분의 이야기를 듣고, 이해할 방법을 찾는 의사다. 책·영상·자료는 진료실에서 나온 질문을 이어가는 작업으로 연결한다.

밝은 쿨 화이트, 잉크색, 코발트 블루를 사용한 편집형 디자인. 큰 한국어 헤드라인을 독립적으로 배치하고 실제 프로필 사진을 왼쪽에, 짧은 소개를 오른쪽에 둔다. 이전 베이지·올리브·명조·우측 프로필 시안을 복제하지 않았다. 모바일에서는 사진 다음 소개로 읽히도록 재배열한다. 브랜드 심벌은 새로 만든 대화 모양의 추상 아이콘이며 기존 공인 로고나 자격 마크가 아니다.

## 완료 기능과 진입 경로

| 경로 | 기능 |
| --- | --- |
| `/` / `/#top` | 첫 화면, 충분히 듣습니다, 실제 인물 사진과 소속 |
| `/#approach` | 환자분 질문을 선택하는 경청·이해·선택 탭 |
| `/#records` | 실제 글 1편, 책 2권, 소개 영상 1편; 전체/글/책/영상 필터 |
| `/#about` | 소개, 소속·학력·진료 관심, 접힌 운영 관련 저술 이력 |
| `/#visit` | 병원 진료 예약 및 위치·이용 안내로 연결 |
| `/robots.txt` | 검토 단계 검색 제외 요청 |
| `/static/*` | CSS, JS, 실제 사진, 글꼴, 라이선스와 파비콘 |

- 모바일 메뉴: 펼치기, 링크 선택 시 닫기, Escape 및 외부 클릭으로 닫기.
- 질문 탭: 클릭, 위/아래 방향키, Home/End, ARIA 탭과 패널 관계.
- 콘텐츠 필터: 선택 상태와 표시 개수를 스크린리더에 전달.
- 소개 영상: 클릭한 뒤에만 youtube-nocookie iframe을 삽입한다. 페이지 진입 시 자동재생·외부 영상 요청 없음.
- 외부 링크: 새 탭 표시, `noopener noreferrer`, 실제 목적지 연결.
- 본문 건너뛰기, 키보드 포커스, 이미지 설명, 움직임 감소 지원.
- 자바스크립트가 없어도 본문, 모든 생각 패널, 콘텐츠, 병원 링크는 유지.
- 예약이나 문의를 수집하는 개인 사이트 폼, 가입·결제·추적 스크립트 없음.

### 새 문안

'충분히 듣습니다'는 본인의 직접 정정 표현을 유지했다. 첫 화면의 나머지 문구, 3개 질문과 생각 패널, 소개 및 콘텐츠 요약문은 사용자 제공 초안 8장을 재편집한 새 홈페이지 문안이다. 새 인터뷰 인용, 실제 환자 발언 또는 최종 승인 문장으로 표시하지 않았다. 임상 결과 보장이나 새 이력을 만들지 않았다.

### 공개하지 않은 항목

전문의 자격, 공식 영문 이름, 가족·어린 시절 일화, 경력 연수·세부 연도, 수술 건수·성공률·성과 수치·후기, 제작 중인 《임플란트, 그다음》, 미채택 설명 영상, 개인 연락처, 미확인 교육 서비스 기능·가격·신청 경로. 인스타그램은 현재 편집상 제외했다.

## 데이터와 개인정보

- 공개 소개는 소스 파일에 정의된 정적 편집 콘텐츠.
- 사용자 데이터 모델과 영구 저장 없음. D1/KV/R2 또는 서드파티 백엔드가 필요하지 않은 소개 사이트.
- 화면의 탭·필터 상태만 현재 브라우저 페이지에서 유지. localStorage·쿠키·서버 저장 없음.
- YouTube 플레이어를 누르면 해당 외부 서비스에 연결됨. 원본 보기 링크도 항상 제공.
- 향후 CMS나 문의 기능을 추가하면 개인정보 및 저장 요구사항을 먼저 확정하고 Cloudflare D1/R2 등으로 설계해야 함.

## 실행과 유지보수

```sh
cd /home/user/webapp
npm run build
pm2 start ecosystem.config.cjs
curl http://localhost:3000
npm test
```

이미 실행 중일 때에는 중복 서버를 시작하지 않는다. 서버를 재시작해야 하면 `pm2 stop webapp`, 3000 포트 확인, 빌드 후 `pm2 restart webapp` 순서로 실행한다. 로그는 `pm2 logs webapp --nostream`으로 확인한다.

프로덕션 배포 명령은 사용자 검토·배포 경로 선택 전 실행하지 않는다. 현재 wrangler 설정은 바인딩 없는 Pages 호환 구성이다.

글꼴은 Pretendard v1.3.9에서 본문 문자만 부분집합으로 만든 OFL 파생본이다. Reserved Font Name 조건에 따라 내부/CSS 이름은 MoonSans로 변경했다. 라이선스는 `/static/font-license.txt`. 문안을 확장할 때 추가 글자가 시스템 폰트로 표시될 수 있으므로 부분집합을 갱신해야 한다.

## 미확인 항목과 권장 다음 단계

### 공개 전에 본인 확인

1. 이번 시각 방향과 '충분히 듣습니다' 외의 새 문안 최종 승인.
2. 대표 칼럼·영상 선정, 최신 적합성과 개인 사이트에서 소개할 범위.
3. 운영 관련 저술을 작은 접힘 영역으로 남길지 여부. 교육상품·신청 동선은 현재 없음.
4. 개인 도메인, 공식 영문 이름, 개인·협업 연락처 공개 여부. 필요하지 않으면 추가하지 않아도 됨.
5. 상세 학력·자격 증빙. 특히 통합치의학과 전문의는 확인 전 본문·메타·구조화 데이터에 모두 넣지 않음.
6. 도서 표지 이용 권한, 새 원고의 출간 및 공개 가능 범위. 현재는 모두 임의 추가하지 않음.
7. 다국어 필요 여부.

### 추가하면 좋은 실제 자산

- 긴 변 2000px 이상, 정면 및 3/4 방향의 여백 있는 상반신 인물 촬영본. 현재 원본은 폭 310~325px 정도만 표시하며 과도하게 확대하지 않음.
- 환자 개인정보와 타인 얼굴이 드러나지 않거나 별도 동의를 확보한 '듣는 장면'의 실제 사진. 생성형 가상 진료 사진으로 대체하지 않을 것.
- 공개·임상 검토·권리가 확인된 설명 도해 또는 영상 1개. 여러 편보다 설명 방식이 잘 드러나는 자료 우선.
- 출판사에서 제공하거나 이용 승인을 받은 실제 도서 표지.

### 정식 공개와 비디치과 연결

1. 사용자의 공개 승인 및 배포 경로 선택(사용자 Cloudflare 계정 또는 Genspark 관리형). 지금은 실행하지 않음.
2. 최종 도메인 DNS/HTTPS 설정, 배포명 및 메타 정보 확정.
3. 개인 도메인 canonical, OG URL/이미지, 사이트맵 설정. 승인 후 noindex와 robots 차단 제거.
4. 실제 폰에서 글꼴·원본 영상 재생·서점·병원 예약 경로 재확인.
5. 서울비디치과 문석준 의료진 페이지에 '치과의사 문석준 개인 홈페이지' 링크를 병원 운영 측이 별도로 반영. 현재 병원 사이트는 수정하지 않음.
6. 개인 사이트에서 병원으로 이동하는 현재 링크는 유지하고 목적지를 명확히 표시.
